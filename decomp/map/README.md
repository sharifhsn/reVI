# Map

`functions.csv` is generated by `revi map <your exe> --out decomp/map/functions.csv`
and committed. One row per `RUNTIME_FUNCTION`: `rva,size,section`.

This file is a **seed**, not a map: it holds only the entry point from the
public import analysis, so the tooling has something to validate against
before anyone with a copy runs the full pass. Replace it wholesale; do not
append.

Regenerate, then run `revi status decomp/map/functions.csv decomp` and commit
both the map and `STATUS.md`.
