# Call graph

Generated by `revi graph` from one build. Three edge sources: `call rel32`,
`jmp rel32` (tail), and no indirect edges — register calls cannot be resolved
statically. `nodes.csv` also carries pointer-table references and import calls.

| File | Content |
|---|---|
| `nodes.csv` | `rva,in_degree,out_degree,table_refs,import_calls,reachable` |
| `edges.csv` | `from,to,kind` (`call` or `jump`) |
| `graph-summary.json` | totals |

## Reading

* 825,041 edges over 299,257 functions.
* 13,140 roots: the entry point, the one export, and every function address
  stored in a pointer table. 82,223 functions (27.5%) are reachable from them.
* Highest in-degree: `0x53d3f80` (19,178 callers), `0x13ba450` and `0x4c04`
  (14,456 each) — allocation, error and dispatch helpers.
* 2,095 functions call an import; 7,554 pointer tables contribute the roots.

The reachable set is a *lower bound*: every indirect call cuts a branch, so
27.5% understates the live code. Treat it as "definitely reachable", not as a
complete partition.
