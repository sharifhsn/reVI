# 0x01fa5340

Alias of `0x01fa5270`: byte-for-byte the same 28-byte body, only the RIP
displacements differ because this copy points at its own global.

* global: **0xaa56410**
* table slot: +0x28 (not +0x30 as in 0x01fa5270)

Same reading, different object and slot:

```cpp
extern char* g;                      // 0xaa56410
bool f() { (*(void (**)(void*))(g + 0x28))(&g); return true; }
```

No own `src/`; the body at 0x01fa5270 compiles to this exactly.
