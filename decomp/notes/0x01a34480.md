# 0x01a34480

Passes the address of a global through a stack slot to a virtual call, then
returns void.

## Original

```
sub  rsp, 28h
lea  rax, [rip+0x48e3425]   ; 0x48e3430, a global
lea  rdx, [rsp+20h]         ; first shadow slot
mov  [rdx], rax             ; slot = &global
mov  rax, [rcx]             ; vtable of `this`
call [rax+40h]              ; ninth slot, args: rcx = this, rdx = &slot
nop
add  rsp, 28h
ret
```

## Reading

```cpp
struct B { virtual void v0(); /* ... */ virtual void v8(void **); };
extern char *g;                                   // 0x48e3430
void f(B *self) { void *p = &g; self->v8(&p); }
```

## Codegen

Ours is 32 bytes against 31: the compiler spills to `[rsp+30h]` and materialises
`rdx` after the store, where the original uses the first shadow slot `[rsp+20h]`
and stores through `rdx`. Same instructions, one slot apart; the shapes tried
(local array, local pointer) all produced our layout.

## Open

* Who writes 0x48e3430? It is passed by address, so the callee likely stores or
  re-registers it, which makes it a handle rather than a plain singleton.
