# 0x043c4370

0x313 bytes. Runs one render job: installs the job and its two payload pointers
into TLS, begins a GPU pass on the command buffer, records the pass into the
payload's ring, commits, invokes the job's own code, then releases everything.

## Reading

```cpp
void run_job(job_ctx *ctx, payload *a, payload2 *b)
{
    tls->job = ctx->item;
    tls->a = a;  tls->b = b;
    if (a) { bind_a(); flush(-1); }
    if (b) { bind_b(); flush(-1); }
    if (dbg_a) hook_a(a);
    if (dbg_b) hook_b(b);
    a->refcount++;
    track(a, &ctx->slot);
    if (b) track(b, &ctx->slot);
    pass p1 = begin_pass(gpu->buf, ctx->item->pass, 0);
    if (p1) push(a, p1);
    if (b) { pass p2 = begin_pass(..., 1); if (p2) push(b, p2); }
    commit();
    invoke(ctx->item);            // 0x1443c3890
    if (p1) pop(a);
    if (b && p2) pop(b);
    if (b) unbind_b(b);
    ctx->[0x10] = finalize(a, 0);
    finish(gpu, ctx->item);
    release(ctx);
    if (after_a) hook_after(a);
    if (after_b) hook_after(b);
    tls->a = 0;
}
```

The two payload pointers may be absent; the job's own function is `item[0][1]`
called with `(item[0][2], item[0][6])` — see `0x1443c3890`, which is exactly that
indirect call.

`a1+0x12290` is a small stack of pass handles, `a1+0x12294` its depth; the depth
is incremented on push and decremented after commit/run.

## Evidence

The body is read instruction-for-instruction from the draft; `0x1443c3890`
(decompile above it) is the invoke thunk. Caller: `0x043c4140` (worker) calls this
with `(item, record.a, record.b)`.

## Codegen

Drafted from the disassembly. The TLS ensure sequence repeats inline (the compiler
re-materialised it per use); keep the call order, not the repetition.

## Open

* TLS slots `0x10e8`, `0x12a8`, `0x1108`, and the payload counters `0x12194` /
  `0x12290..` — one of these is the job pointer, `0x12a8` is cleared at the end.
* `sub_4fa85e0` / `sub_4fa9340` / `sub_55cc020` / `sub_55cc0c0` are the GPU pass
  API; named `bind_*`, `begin_pass`, `commit` by position only.
* Debug flags `0x149c3b788`, `0x149c3b790`, `0x149c3b798`, `0x149c3b7a0` and `0x149c3b740` (the GPU object) are unread globals.
