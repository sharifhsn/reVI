# 0x056a1ec8

Entry point of `game_scarlett_master.exe` (`IMAGE_OPTIONAL_HEADER::AddressOfEntryPoint`).
Reached once, from the Windows loader, after CRT init has run its static
initialisers; it does not return to the loader on the normal path (the title
ends through its own exit path).

Behaviour to confirm with the oracle before this goes past `ported`:
* which arguments are read off the stack/registers (MSVC passes `argc`/`argv`
  only when the entry is a `main` wrapper);
* whether the frame installs SEH or a VEH handler;
* the call into the GDK app object and where the message loop starts.

This is the first claim and only proves the tooling; the size (64 bytes) is a
placeholder until `revi map` is run on a real copy.
