# 0x0056a1ec8

0x12 bytes. Process entry point (`AddressOfEntryPoint`). Calls one function,
then tail-jumps into a second and hands its return value back to the loader.


## Reading

`sub rsp,0x28` only exists to give the first call shadow space.
