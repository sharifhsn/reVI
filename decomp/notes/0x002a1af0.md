# 0x002a1af0

0x9C bytes. Looks a record up by a 32-bit tag and a 64-bit id under an
object's read lock, asks the record three questions through its vtable, and
answers whether the current value sits outside a window.

```
push rsi ; push rdi ; push rbx ; sub rsp,0x40 ; vmovaps [rsp+0x30],xmm6
edi = edx                       ; a1
rbx = rcx                       ; this
rdx = rcx + 0x30                ; this->lock
rcx = rsp + 0x28                ; guard storage
esi = r8d                       ; a2
call sub_347fd0                 ; read-lock acquire(this->lock), guard at rsp+0x28
rcx = [rbx+4]
rdx = [rbx+8]
r8d = edi ; r9d = esi
call sub_358990                 ; lookup(tag, id, a1, a2)
test rax,rax ; jz .zero
rsi = rax
rax = [rsi]                     ; vftable
rcx = rsi
call [rax+0x58]                 ; predicate(record)
test al,al ; jz .zero
rax = [rsi] ; rcx = rsi
call [rax+0x38]                 ; float a(record)
rax = [rsi] ; rcx = rsi
vmovaps xmm6, xmm0
call [rax+0x40]                 ; float b(record)
xmm1 = [0x5fc6f0c]              ; 0.99999994f
xmm0 = (xmm0 < xmm6)            ; b < a
xmm1 = (xmm6 < xmm1)            ; a < eps
xmm0 = xmm1 | xmm0
esi = xmm0                      ; all-ones masks
jmp .unlock
.zero:
esi = 0
.unlock:
rcx = [rsp+0x28]
call sub_2c59f0                 ; read-lock release(guard)
vmovaps xmm6, [rsp+0x30]
sil &= 1
eax = esi
ret
```

## Reading

```cpp
bool f(obj_t *o, uint32_t tag_unused, unsigned a1, unsigned a2)
{
    read_lock guard(&o->lock);                 // 0x347fd0 / 0x2c59f0
    rec_t *r = lookup(o->field_0x4, o->field_0x8, a1, a2);  // 0x358990
    bool out = false;
    if (r && r->vtbl->pred(r)) {                          // slot 0x58
        float a = r->vtbl->get_a(r);                      // slot 0x38
        float b = r->vtbl->get_b(r);                      // slot 0x40
        out = (b < a) | (a < 0.99999994f);                // strict, NaN-boxed masks
    }
    unlock(guard);
    return out;
}
```

`out` is 1 when the record's value `a` is above `b` **or** below the constant
at `0x5fc6f0c` (`0x3f7fffe f`, 0.99999994f). Both comparisons are
`VCMPLTPS` against all-ones masks, then ORed, then only bit 0 is returned, so NaN
on either side yields 1.

The lock is a per-thread-recursive reader count (`this->lock + 0` bits
0x1ff0000, cmpxchg by `+0x100`, writer wait on `+0x8`, recursion id in
`TEB->ThreadLocalStoragePointer + 0x1438`); `0x347fd0` acquires it and
`0x2c59f0` releases it. The guard slot is the pointer passed back to the
release, nothing else.

## Evidence

Instruction-by-instruction from the image; `0x347fd0` and `0x2c59f0` read as the
acquire/release pair (same TEB fields, mirrored cmpxchg direction).

Not yet run end to end: the body needs a live object with a populated vtable and
a record in the lookup table. With `a0 = 0` it faults at `[0+4]`/lock, so a run
must fabricate the object at least.

## Codegen

Drafted from the disassembly; slot offsets and the OR-of-masks are the parts to
keep exact. `xmm6` is caller-nonvolatile on Win64 and is saved/restored around
the two float calls.

## Open

* `sub_358990` (lookup) argument meaning: `[this+4]` is a u32 tag, `[this+8]` a
  u64 id, `a1`/`a2` pass through — which of the four selects the table is open.
* Slot roles at 0x38 / 0x40 / 0x58 are positional; a second caller with
  different slots would name them.
* The threshold is 1.0f minus one ULP: a "value must reach one" test. A second
  caller would say what the quantity is counted in.
