# 0x01fa5480

Alias of `0x01fa5270`, third copy of the same 28-byte body. Only the two RIP
displacements differ, and they point at this copy's own global.

* global: **0xaa56619**
* table slot: +0x28

```cpp
extern char* g;                      // 0xaa56619
bool f() { (*(void (**)(void*))(g + 0x28))(&g); return true; }
```

Three globals at 0xaa56410, 0xaa56540 and 0xaa56619, each a singleton with the
same registration shape. Finding their writers gives the class behind them.
