# 0x05600728

52 bytes. Last-chance path: clears the per-process unhandled exception filter,
runs the default filter on the given exception information, then terminates the
process with `0xC0000409` (`STATUS_STACK_BUFFER_OVERRUN`).

```

SetUnhandledExceptionFilter(0)

```

(`api-ms-win-core-errorhandling-l1-1-0.dll`), `GetCurrentProcess`
(`api-ms-win-core-processthreads-l1-1-0.dll`), `TerminateProcess`. The last
call is a tail jump, so the return value of `TerminateProcess` is this
function's.
